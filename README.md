# Lesia Tsyvienkova — Portfolio

A focused personal portfolio for Lesia Tsyvienkova, bringing together conversion copy, UI/UX, creative direction and front-end implementation. The site is designed to feel like a boutique creative studio rather than a generic developer showcase.

## Live Portfolio

[lesia-portfolio-live.vercel.app](https://lesia-portfolio-live.vercel.app)

## Featured Case

### Aesthetic Clinic Treatment Page Makeover

The first published case explores how a complex aesthetic-treatment decision can be made clearer, calmer and easier to navigate through:

- conversion-minded copy;
- UX structure and content hierarchy;
- premium but approachable UI direction;
- responsive front-end implementation.

## Transparency

The featured case is an independent, unofficial spec concept created to demonstrate Lesia Tsyvienkova’s approach to conversion copy, UX and visual direction. It is not presented as commissioned client work, and no performance results are claimed.

## Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- Vercel

The project intentionally uses a lightweight static stack. There is no framework or build step to maintain, and the content remains easy to update as the portfolio grows.

## Repository Structure

```text
/
├── README.md      # Project overview, transparency and maintenance notes
├── index.html     # Semantic portfolio page and featured case content
├── styles.css     # Visual system, layouts and responsive behaviour
├── script.js      # Navigation, scroll state and accessible reveal behaviour
└── vercel.json    # Minimal Vercel configuration for the static site
```

Future case studies can be added under dedicated routes such as `cases/project-name/` when they are ready to publish. Empty case directories are intentionally not included.

## Portfolio Direction

This repository is the foundation for a curated multi-case portfolio. New work will be added gradually, with each case clearly identifying its scope, Lesia’s role and whether it is commissioned work or an independent concept.

The guiding principles are simple:

- depth over volume;
- strong thinking presented clearly;
- honest project context;
- no invented clients, metrics or performance claims;
- consistent quality across copy, design and implementation.
